Удирдлагын самбарт нэвтрэх

Supabase холбогдоогүй байна — нэвтрэх боломжгүй.

1. Supabase → SQL Editor дээр supabase/setup.sql-ийг ажиллуулна.
2. Project Settings → API Keys → anon / public түлхүүрийг хуулна.
3. supabase-config.js доторх anonKey талбарт тавьж commit хийнэ.

Шинээр бүртгүүлсэн хэрэглэгч эхлээд staff эрхтэй байна. Үндсэн админ (owner) л админ эрх олгоно.
